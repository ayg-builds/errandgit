General

Open all

What language can I ask questions in?

Amazon Q Developer can respond to questions in many languages, including English, Mandarin, French, German, Italian, Japanese, Spanish, Korean, Hindi and Portuguese, and more.

What data does Amazon Q Developer store when you interact with it the console, IDE, AWS documentation, and through Microsoft Teams and Slack, and how is it used?

Amazon Q Developer stores your questions, its responses, and additional context, such as console metadata and code, in your integrated development environment (IDE) to generate responses to your questions. For the Amazon Q Pro and Free Tiers, customer content, including code snippets, conversations, and file contents open in the IDE might be stored and processed to provide and maintain the service. With usage in Microsoft Teams and Slack, Amazon Q Developer may store or process customer information, such as channel configurations and permissions, Microsoft Teams team identifiers, Slack workspace identifiers and channel names, notifications, user inputs, and generated responses and images in any of the commercial AWS Regions.

Amazon Q Developer Pro and Amazon Q Business do not use your content for service improvement.

Amazon Q Developer Free Tier might use certain content for service improvement, for example, to provide better responses to common questions, fix Amazon Q operational issues, for debugging, or for model training. Content that AWS might use for service improvement includes, for example, your questions to Amazon Q and the responses and code that Amazon Q generates.

The way you opt out of Amazon Q Developer Free Tier using content for service improvement depends on the environment where you use Amazon Q. For the console, Console Mobile Application, Microsoft Teams, Slack, and AWS websites, opt out by configuring an AI services opt-out policy in AWS Organizations. For more information, see AI services opt-out policies in the AWS Organizations User Guide. In the IDE, adjust your settings in the IDE to opt out.

Your trust, your privacy, and the security of your data are our highest priority and we implement appropriate and sophisticated technical and physical controls, including encryption at rest and in transit, designed to prevent unauthorized access to, or disclosure of, your data and ensure that our use complies with our commitments to you. See https://aws.amazon.com/compliance/data-privacy-faq/ for more information.

How do I get started with Amazon Q Developer in the console, on the AWS website, and in AWS documentation?

To access Amazon Q Developer in the console, you need to first log in to the console, and then ensure that you have the appropriate permissions to use Amazon Q Developer. You can contact your administrator to enable your account. Once you are able to see the Amazon Q Developer icon in the console sidebar, select the icon to open the Amazon Q Developer window, and then ask questions related to AWS. For more details, see Getting started with Amazon Q Developer or read the documentation.

Is Amazon Q Developer available on mobile devices?

You can access the Amazon Q Developer conversational capabilities available in the console on a mobile device using the Console Mobile Application. When using the Console Mobile Application, you get account-level Amazon Q Developer Free Tier limits. To learn more about the Amazon Q Developer Free Tier, visit the Amazon Q Developer pricing page. You will not be able to access the Amazon Q Developer instance selection in Amazon Elastic Compute Cloud (Amazon EC2) or the Amazon Q Developer network reachability analysis using the Console Mobile Application.

Can I use Amazon Q Developer in team chat applications?

Amazon Q Developer is available in Microsoft Teams or Slack. To learn more, see the documentation.

How can I manage access control and permissions when using Amazon Q Developer in a chat application?

Customers can use chat applications policies and multi-account management services in AWS Organizations to determine which permissions models, chat applications, and chat workspaces can be used to access their accounts. Service Control Policies (SCPs) can be used to control tasks executed from chat channels in your organization. Amazon Q Developer channel configurations use IAM role-based permissions scope when running CLI-based commands. See Understanding Amazon Q Developer permissions documentation for more details.

What audit tracking capabilities are available in chat applications when using Amazon Q Developer?

Amazon Q Developer provides an audit log of CLI-based commands and actions it executes in CloudWatch Logs. This log includes executed commands and their chat workspace/tenant ID, channel ID, and channel user ID attributes. The audit log events in CloudWatch Logs are always enabled and can't be disabled. Refer to the Amazon Q Developer in chat channels User Guide for details.

Which IDEs does Amazon Q Developer support?

Amazon Q Developer currently supports Visual Studio (VS) Code, IntelliJ IDEs, and Eclipse (preview). To get started with Amazon Q Developer in the IDE, see Getting started with Amazon Q Developer or read the documentation.

Which code languages and IDEs does Amazon Q Developer support?

Available as part of the AWS Toolkit for VS Code and JetBrains, Amazon Q Developer currently supports conversations in English, and the Python, Java, JavaScript, TypeScript, C#, Go, Rust, PHP, Ruby, Kotlin, C, C++, shell scripting, SQL, and Scala programming languages.

In which AWS Regions are Amazon Q Developer capabilities available?

For information on where you can use Amazon Q Developer, see Supported Regions for Amazon Q Developer.

In which AWS IAM Identity Center Regions are Amazon Q Developer subscriptions supported?

See Supported Identity Center Regions for Amazon Q Developer for more information on the Identity Center regions in which Amazon Q Developer subscriptions are supported.

Does Amazon Q Developer use cross-Region inference?

Amazon Q Developer is powered by Amazon Bedrock, and uses cross-Region inference to distribute traffic across different AWS Regions to enhance large language model (LLM) inference performance and reliability. With cross-region inference, you get:

  • Increased throughput and resilience during high demand periods
  • Improved performance
  • Access to newly launched Amazon Q Developer capabilities and features that rely on the most powerful LLMs hosted on Amazon Bedrock

At the Amazon Q Developer Pro tier, your data is stored in the Region where your Amazon Q Developer profile was created. At the Amazon Q Developer Free tier, your data is stored in a Region in the US. Data processed during diagnosing console error sessions is stored in the US West (Oregon) Region. All other data is stored in the US East (N. Virginia) Region.

With cross-region inferencing, your requests to Amazon Q Developer may be processed in a different Region within the geography where your data is stored. For more information, see Cross-region inference in the Amazon Q Developer User Guide.

What programming languages and IDEs does Amazon Q Developer support?

Available as part of the AWS Toolkit for VS Code and JetBrains, Amazon Q Developer currently supports Python, Java, JavaScript, TypeScript, C#, Go, Rust, PHP, Ruby, Kotlin, C, C++, shell scripting, SQL, Scala, JSON, YAML, and HCL. In addition to VS Code and the JetBrains family of IDEs—including IntelliJ, PyCharm, GoLand, CLion, PhpStorm, RubyMine, Rider, WebStorm, DataGrip, Eclipse (preview), and Visual Studio—Amazon Q Developer is available for AWS Cloud9, the Lambda console. Amazon Q Developer is also available for your favorite command lines, including macOs terminal, iTerm2, and the built-in VS Code terminal.

How is my content protected when transmitted?

Your content is transmitted using the TLS protocol to ensure secure communication between your IDE and the Amazon Q Developer service. Content is encrypted in transit to prevent eavesdropping or man-in-the-middle attacks. For Amazon Q Developer Free Tier users, we might retain content for the purpose of service improvement, based on a user's settings. We store this content in a secured manner with encryption at rest and strict access controls.

Does Amazon Q Developer use my content to train any models?

For users who access Amazon Q Developer with the Pro Tier, your content is not used to train any underlying FMs. AWS might collect and use client-side telemetry and usage metrics for service improvement purposes for both the Pro and Free Tiers. You can opt out of this data collection by adjusting your settings in the IDE. For the Amazon Q Free Tier, customer content, including code snippets, conversations, and file contents open in the IDE might be stored and processed to provide and maintain the service. Unless explicitly opted out, content might also be used to enhance and improve the quality of FMs. Your content will not be used if you use the opt-out mechanism described in the documentation. For more information, see Sharing your data with AWS.

How does Amazon Q Developer relate to AWS Chatbot?

As of February 19, 2025, AWS Chatbot is now named Amazon Q Developer. All the functionality of AWS Chatbot is now provided as part of Amazon Q Developer. Microsoft Teams and Slack chat application names have changed from AWS Chatbot to Amazon Q Developer. The service APIs, SDK, service endpoints, IAM permissions, and region availability are not affected by this change. The notifications and responses received in the channels will display Amazon Q as the application name instead of AWS. For existing AWS Chatbot customers, there is no change to current usage, pricing, setup, and functionality other than using the “@Amazon Q” mention to run tasks. Any Slack Automation Workflows that trigger commands within the AWS Chatbot app won't change with this renaming. If existing users prior to February 19th send messages to Slack channels programmatically using Webhooks or the API with <@aws>, these users will need to change how they invoke the app programmatically. Read the documentation for more details.

Privacy

Who owns the code generated by Amazon Q Developer?

Just like with your IDE, you own the code that you write, including any code suggestions provided by Amazon Q Developer. You are responsible for the code that you write, including the Amazon Q Developer suggestions that you accept. Always review code suggestions before accepting them, and you might need to make edits to ensure that the code does exactly what you intended.

Does Amazon Q Developer use my content to train any models?

For users who access Amazon Q Developer with the Pro Tier, your content is not used for service improvement, or to train any underlying foundation models (FMs). Unless explicitly opted out, content from Amazon Q Developer Free Tier might also be used to enhance and improve the quality of FMs. Your content will not be used if you use the opt-out mechanism described in the documentation. For more information, see Sharing your data with AWS.

Is Amazon Q Developer included in AWS’s latest SOC report?

Yes. Amazon Q Developer is included in the latest SOC 1/2/3 reports. Customers can download these reports in the AWS management console via AWS Artifact.

My legal and application security teams have additional questions before approving the use of Amazon Q Developer. Is there additional documentation available for them to review?

Yes. Contact your AWS account team and ask for the Service Accelerator Document for Amazon Q Developer. If your organization has a mutually signed NDA with AWS then your account team will share the correct documents.

How can I get started with Amazon Q Developer in the IDE?

For VS Code or JetBrains, install the Amazon Q IDE extension through the respective extension or plugin marketplace. For Visual Studio, install the AWS Toolkit with Amazon Q extension. Then, authenticate with AWS Builder ID or AWS IAM Identity Center. After authenticating, Amazon Q Developer can be found in the activity bar in VS Code or the tool window anchored in the top right in JetBrains. For more help getting started with Amazon Q Developer, see Getting started with Amazon Q Developer.

What are some tasks that Amazon Q Developer can help with in the IDE?

With the Amazon Q Developer agentic coding experience, you can go from a natural language prompt to an application feature right from your IDE or Amazon Q Developer CLI. Amazon Q Developer understands your workspace structure and breaks down your prompt into logical implementation steps and intelligently performs actions on your behalf to accelerate development. You can collaborate with Amazon Q Developer to review and iterate on the implementation.

What can I do to get the most relevant recommendations from Amazon Q Developer in the IDE?

Relevant information about programming languages, frameworks, and tools being used for your tasks can greatly aid in obtaining accurate responses. Breaking down complex problems into smaller components helps in receiving more targeted assistance for the individual components. If an answer is unclear, you are encouraged to request clarifications from Amazon Q Developer. Please also consider experimenting and iterating on your questions and prompts, as programming often involves trying different approaches. With the Amazon Q Developer customization capability, you can customize Amazon Q Developer to generate more relevant inline code recommendations by making it aware of your internal libraries, APIs, best practices, and architectural patterns.

What contextual information does Amazon Q Developer use in the IDE?

Amazon Q Developer uses the following contextual information while answering questions: 1. Current conversational context, like questions asked and answers and code generated in the conversation panel. 2. The IDE context, including the selected code line, snippet, or functions in the file, as well as the filename and the repository that the developers are currently working on.

What is the Amazon Q Developer agentic coding experience?

Amazon Q Developer's agentic coding experience can intelligently take actions on your behalf. It can read your project files to intelligently build the context it needs without requiring complex prompting, suggest code diffs, eliminating the need to copy and paste code snippets, and generate and run shell commands based on the task. This helps Q Developer create code, generate unit tests, and perform code reviews significantly faster through natural language conversations.

Throughout the interaction, Q Developer is transparent with its reasoning process, and provides continuous status updates as it works through the tasks, actively incorporating your feedback and changes along the way.

How I get started with Amazon Q Developer agentic coding experience?

The Amazon Q Developer agentic coding experience is in the IDE plugins and CLI are available to Amazon Q Developer Pro customers and Amazon Q Developer Free Tier customers, with limits. See Getting started with Amazon Q Developer or read the documentation to learn more.

How can I verify that code generated by Amazon Q Developer is safe?

AWS provides developers with services such as AWS Identity and Access Management Access Analyzer, Amazon Virtual Private Cloud (Amazon VPC) Network Access Analyzer, and Amazon CodeGuru to help verify code and configuration security. CodeCatalyst automatically creates deployment pipelines that use these tools to help validate that code changes are tested and safe to deploy.

What is the Amazon Q Developer reference tracker?

The Amazon Q Developer reference tracker detects whether a code suggestion might be similar to publicly available code. The reference tracker can flag such suggestions with a repository URL and project license information or optionally filter them out. You can then more easily find and review the referenced code and see how it is used in the context of another project before deciding to use it. All references are logged for you to review later to ensure that your code flow is not disturbed, and you can keep coding without interruption.

How does Amazon Q Developer code generation work?

As you write code, Amazon Q Developer analyzes the English language comments and surrounding code to infer what code is needed to complete the task at hand. Amazon Q Developer suggests one or more code snippets directly in the code editor, accelerating your work. Amazon Q Developer code suggestions are based on LLMs trained on billions of lines of code, including open source and Amazon code. You can quickly and more easily accept the top suggestion (tab key), view more suggestions (arrow keys), or continue writing your own code. Always review a code suggestion before accepting it, and you might need to edit it to ensure that it does exactly what you intended.

What data does Amazon Q Developer collect to provide code suggestions?

Amazon Q Developer uses your content--such as code snippets, comments, cursor location, and contents from files open in the IDE--as inputs to provide code suggestions.

What is the AI–powered code remediation capability of Amazon Q Developer?

You can scan your code to identify hard-to-find security vulnerabilities and get code suggestions to help remediate the identified issues. Built-in security scanning is designed to detect issues such as exposed credentials and log injection. Generative AI–powered code suggestions help to remediate the identified vulnerabilities and are tailored to your application code, so you can quickly accept fixes with confidence. Security scanning is available for Java, Python, JavaScript, and for TypeScript, C#, AWS CloudFormation (YAML, JSON), AWS Cloud Development Kit (AWS CDK) (TypeScript, Python), and HashiCorp Terraform (HCL). Code suggestions to help remediate vulnerabilities are currently available for code written in Java, Python, and JavaScript.

Will Amazon Q Developer produce code that looks similar to publicly available code?

As generative AI, Amazon Q Developer creates new code based on what its underlying models have learned from the code that they were trained on and the context that you provided in code and comments. While Amazon Q Developer is not designed to reproduce code from training data, it is possible that on rare occasions it will generate code that closely matches publicly available code. If Amazon Q Developer detects that its output matches publicly available code, the built-in reference tracker will notify you with a reference to the license type (for example, MIT or Apache) and a URL for the publicly available code. You can then more easily find and review the referenced code and see how it is used in the context of another project before deciding whether or not to use it. To ensure that your coding flow is not disturbed, all references are logged for you to review later, so you can keep coding without interruption.

Can I prevent Amazon Q Developer from recommending code with code references?

Yes. In the configuration setting for Amazon Q Developer, you can deselect the Include Suggestions With Code References option. This will prevent Amazon Q Developer from making suggestions that include references to known licensed open source code. For Amazon Q Developer Free Tier users, this setting is available in the IDE. With Amazon Q Developer Pro, the AWS administrator can centrally configure this setting on an organization level from the console.

Will Amazon Q Developer produce toxic or biased code?

Amazon Q Developer can filter out code suggestions that include toxic phrases and suggestions that contain commonly known code structures that indicate bias.

Will Amazon Q Developer recommend code with security vulnerabilities?

Amazon Q Developer is designed to prevent suggesting code with security vulnerabilities, and as many security vulnerabilities are filtered out as possible. However, given the generative nature of Amazon Q Developer we cannot completely rule out code suggestions with security issues. Therefore, Amazon Q Developer comes with a built-in code-scanning feature that detects security vulnerabilities within your Python, Java, and JavaScript projects, including code suggestions from Amazon Q Developer and code written by you.

Does Amazon Q Developer only work in the English language when generating code suggestions?

Amazon Q Developer was trained on various data sources, including Amazon and open source code. Amazon Q Developer has been trained and validated to generate code suggestions from English language comments. Given the various examples in the training dataset, it is possible that Amazon Q Developer might provide code suggestions from comments written in non-English languages; however, this is not a supported use case.

What is Amazon Q Developer for command line?

Amazon Q Developer for command line helps developers be more productive in the command line with contextual CLI completions, inline documentation, and AI natural language–to-bash translation. Amazon Q Developer for command line integrates with a developer’s existing command line so developers don’t have to change the tools they use to start benefiting.

How do CLI completions work?

While a user types in their command line, Amazon Q Developer shows inline completions and documentation for over 250 CLI tools.

For example, a developer can type “git” and see a list of all the git subcommands, options, and arguments, ordered by their usage recency. A developer could also type “npm install” and see a list of all the node packages available to install. Additionally, a developer could type “aws” and see a list of all the AWS subcommands available.

How does natural language–to-bash translation work?

Amazon Q Developer for CLI can take natural language text prompts (such as "reverse my most recent git commit") and convert them into instantly executable bash code.

To get started, run Amazon Q, insert a prompt, and then execute the bash.

What terminals, shells, and IDEs does Amazon Q Developer for command line support?

Amazon Q Developer for command line currently supports integrations with the following tools:
1. Operating systems: macOS
2. Shells: bash, zsh, fish
3. Terminal emulators: iTerm2, macOS terminal, Hyper, Tabby
4. IDEs: Terminal inside VS Code
5) CLIs: 250+ of the most popular CLIs such as git, aws, docker, npm, yarn (see Github)

For support with Jetbrains IDEs (except Fleet), Alacritty, Kitty, and Wezterm on macOS, run cw integrations install input method.

Can I turn off CLI completions?

Yes.
1. Run "cw" to open the settings page.
2. Select the CLI Completions tab.
3. Toggle the switch in the top right corner of the page to Off.

Can I customize code recommendations in Amazon Q Developer in the IDE?

Yes. You can customize Amazon Q Developer to generate even more relevant inline code recommendations and chat responses by making it aware of your internal libraries, APIs, best practices, and architectural patterns.

What languages are supported when creating a customization?

Currently, you can customize Amazon Q Developer recommendations on code bases written in Java, JavaScript, TypeScript, and Python. Files written in other languages supported by Amazon Q Developer (C#, Go, Rust, PHP, Ruby, Kotlin, C, C++, shell scripting, SQL, and Scala) will not be used when creating the customization or when providing customized recommendations in the IDE based on your internal code repositories.

Are there any usage limits when creating or activating customizations?

You can create up to eight customizations based on your internal code bases. You can keep up to two code customizations active at the same time.

How can I get started customizing Amazon Q Developer code recommendations?

You can securely connect your code repositories to Amazon Q Developer using the console. Amazon Q Developer administrators can manage access to a private customization from the console, so only specific developers have access.

In which service consoles can I ask Amazon Q Developer to help me diagnose errors?

Amazon Q Developer can help you diagnose common errors in the Amazon Simple Storage Service (Amazon S3), Amazon EC2, AWS Lambda, and Amazon Elastic Container Service (Amazon ECS) service consoles. When an error appears in one of the supported consoles, you can choose the Diagnose with Amazon Q Developer button next to the error to get context on what might have caused the error, as well as step-by-step instructions on implementing potential fixes.

What data does Amazon Q Developer access in my account when helping me diagnose errors?

To analyze the error, Amazon Q Developer queries information—such as Account ID, AWS Resource identifiers, or the error message—in the scope of approved policy and user permissions.

What can I do if Amazon Q Developer wasn't able to diagnose my error or answer my question?

If you need more specific help or guidance, you can contact AWS Support. Amazon Q Developer integrates with AWS Support, so you can seamlessly connect with support agents from within the Amazon Q Developer interface if additional assistance is required. This option helps remove obstacles in your self-service experience. This integration with AWS Support is available to all AWS customers accessing Amazon Q Developer through the console, and it will honor the entitlements of the customer's support plan.

How can Amazon Q Developer help reduce time to operational insights?

During operational incidents, there are massive amounts of data flowing from multiple sources, including logs, metrics, and traces across Amazon CloudWatch, Amazon OpenSearch Service, Amazon S3, and other sources. The combination of high data volume and diverse sources makes it difficult to quickly find and correlate relevant information during critical incidents. Amazon Q Developer in Amazon OpenSearch Service helps you quickly investigate issues, analyze patterns, and create visualizations using in-context assistance and natural language interactions.

What types of questions can Amazon Q Developer answer about building on AWS?

Amazon Q Developer has been trained on 17 years' worth of AWS expertise. Therefore, it can help you get started with AWS services, learn about best practices when architecting and building your applications, find the right service for the job, list and describe AWS resources running in your account (in preview), and much more. For example, you can ask Amazon Q Developer, "How can I build a web application on AWS?" right in the AWS Management Console, and Amazon Q Developer will walk you through the steps and provide references where you can learn more.

Can Amazon Q Developer see what AWS resources I have running in my account?

Amazon Q Developer does not have complete visibility into the resources in your account, but it can list and describe certain resources you’re using (in preview), such as Amazon S3 buckets or Amazon EC2 instances. Amazon Q Developer will direct you to the best billing resources available but currently cannot provide billing information about your account or organization bills and costs. However, Amazon Q Developer can now help you retrieve and analyze cost data from AWS Cost Explorer (preview).

Can I ask Amazon Q Developer to make application changes from the console?

No. Developers can only start the process by telling Amazon Q Developer in the console that they want to make changes to their application. After the initial interaction, Amazon Q Developer directs developers to their preferred IDE or their project in CodeCatalyst where they can continue the same conversation.

Are there rate limits for Amazon Q Developer usage in chat applications?

Yes, Amazon Q Developer is subject to rate limits from Microsoft Teams and Slack. Refer to the Microsoft Teams Developer documentation and Slack Web API documentation for details.

What Amazon Q Developer features are available in chat applications?

Using Amazon Q Developer in your chat application of choice, you can receive notifications about operational events, security findings, or budget alerts right in your chatroom, where your entire team can see and discuss them. Ask Amazon Q Developer questions in natural language to understand the state of your resources, troubleshoot issues, and remediate incidents. Get real-time notifications about AWS events and CloudWatch alarms, run CLI-based commands including Systems Manager automation documents and AWS Lambda functions with built-in IAM and AWS Organizations-based controls, and more - all within chat channels. With the built-in customizability, SDK support, custom notifications, custom action buttons, and command aliases, you can integrate your DevOps and incident response processes in your chat channels.

How do I get started with Amazon Q Developer and run commands in chat applications?

To get started with Amazon Q Developer, go to the Amazon Q Developer console, create a configuration for Microsoft Teams or Slack with Amazon Q Developer permissions, and add the Amazon Q Developer chat application to your channels. You can customize your ChatOps experience by configuring specific notification channels, setting up command permissions, and tailoring the interaction patterns to match your team's workflows. To run commands and find answers, type '@Amazon Q' in your configured chat channel, followed by your desired AWS CLI command or natural language question. Check resource status, retrieve CloudWatch logs, view CloudWatch metrics, or execute Systems Manager runbooks directly from chat, using standard AWS CLI syntax. Visit the Amazon Q Developer documentation for more details.

How can I customize Amazon Q Developer for my DevOps in chat applications?

You can customize Amazon Q Developer to integrate your DevOps and operational workflows in chat channels. Configure chat channels to monitor resources in one or more accounts across multiple regions, send notifications about operational events, or set up custom notifications for your application events. You can also customize action buttons on notifications and command aliases to quickly run CLI-based commands to diagnose issues and operate resources.

What types of notifications can I receive through chat applications using Amazon Q Developer?

Amazon Q Developer delivers a wide range of notifications from your AWS resources directly to your chat channels. You can receive notifications for Amazon CloudWatch alarms, AWS Health, AWS Security Hub findings, GuardDuty discoveries, CloudFormation stack updates, and budget alerts. Sending notifications works with any AWS service that publishes to Amazon SNS and User Notifications, giving you comprehensive coverage of your AWS infrastructure. You can select specific event types that matter to your team. You can also customize your notifications. For more information, see Custom notifications in Amazon Q Developer in chat applications.

What are the transformation capabilities of Amazon Q Developer and how can I access them?

Amazon Q Developer offers transformation capabilities for porting of .NET Framework applications to cross-platform .NET modernization and Java upgrades capabilities to upgrade from source versions v8, v11, v17, v21 to target versions v17 or v21. The .NET porting capabilities are available in the Visual Studio IDE environment. The Java upgrade capabilities are available in the VS Code and JetBrains environments, and also on CLI.

How does Amazon Q Developer’s AI-driven modernization approach differ from traditional modernization tools?

Amazon Q Developer transformation capabilities leverage generative AI and machine learning (ML) algorithms to provide you with a more intelligent, adaptive, and automated migration experience. Unlike traditional tools that often require extensive manual input and decision-making, Amazon Q Developer can autonomously analyze your environment, suggest optimal migration strategies, and adapt plans in real-time based on changing conditions. Amazon Q Developer’s transformation capabilities continually learn from each modernization, improving recommendations and automation processes. This results in faster, more accurate modernization planning and execution, reducing the reliance on scarce modernization expertise and minimizing the risk of human error.

Which transformation workloads does Amazon Q Developer support?

Amazon Q Developer supports porting .NET Framework applications to cross-platform Linux-ready .NET, and upgrading Java from source versions 8, 11, 17, or 21 to target versions 17 or 21.

Will I be billed for Amazon Q Developer transformation capabilities?

Amazon Q Developer transformation capabilities for Java upgrades and .NET porting are available to users with the Amazon Q Developer Free Tier and with an Amazon Q Developer Pro subscription. For pricing details, please refer to the pricing section.

How does Amazon Q Developer port .NET applications?

Amazon Q Developer streamlines the modernization of Windows-based .NET Framework applications by transforming them into cross-platform .NET applications that can run on Linux. Working directly within Visual Studio, developers can initiate the transformation of either a single project or an entire solution. The process begins when the project or solution code and its dependencies are packaged and sent to AWS for transformation. Developers can track the progress of this transformation without leaving their IDE. Once Amazon Q Developer completes the process, the transformed project files are returned to the IDE where developers can review the changes. After examining the transformed code, developers can merge these changes into their codebase and proceed with testing.

What project types and .NET versions do Amazon Q Developer transformation capabilities support for .NET porting?

Amazon Q Developer supports modernizing C# .NET applications for the following project types: Console application, class library, web API, WCF Service, business logic of Model-View-Controller (MVC), and Single Page Applications (SPA). The service also supports replacement of Private NuGet Framework package dependencies with their corresponding .NET 8 versions, in addition to supporting Microsoft authored public NuGets.

Amazon Q Developer also supports upgrading Top-35 popularly used 3rd party libraries, such as Newtonsoft, MongoDB, to their .NET 8 versions as well. For Windows .NET applications dependent on Internet Information Server (IIS), only default IIS configurations are supported for porting to cross-platform .NET. Q Developer supports transforming applications written in .NET Framework versions 3.5+, .NET Core 3.1, .NET 5, 6, 7 to cross-platform .NET 8.

Which languages and language versions does Amazon Q Developer’s Java transformation capabilities support?

Using the Amazon Q Developer, customers can upgrade the Java version of their applications using Maven from source versions 8, 11, 17, or 21 to target versions 17 or 21. They can also continue to upgrade libraries and frameworks used in Java 17 or Java 21 compatible applications without upgrading JDK versions.

Which IDEs do Amazon Q Developer agents for Java and .NET transformation support?

Amazon Q Developer support for Java upgrades is available through the AWS Toolkit for JetBrains and VS Code IDEs. Support for .NET application porting from Windows to Linux is available through Visual Studio IDEs.
